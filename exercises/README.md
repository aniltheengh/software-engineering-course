# Exercises

One exercise set per module. Do them after (or alongside) the module's primary resource.

## Rules
- Write every solution in C# yourself. Look things up in documentation, not in finished solutions.
- Difficulty: ★ warm-up · ★★ core · ★★★ challenge. Do all ★ and ★★; do at least two ★★★ per module.
- Where an expected result is given, your program must reproduce it.
- Keep solutions in `solutions/NN-module-name/ExerciseNN/` in your own copy of this repository, one commit per exercise.
